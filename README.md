# 🛰️ Satellite Image Processing using Python

## 📌 Overview
This project performs basic image processing using Python and OpenCV.

## 🚀 Features
- Grayscale conversion
- Gaussian blur
- Edge detection
- Saves output images

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy

## ▶️ How to Run
1. Install libraries:
   pip install numpy opencv-python

2. Run:
   python project.py

## 📂 Files
- project.py
- image.jpg
- output images
